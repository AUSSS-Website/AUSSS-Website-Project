# ausss-ainshams.org
#
# Everyone may crawl the public site, including the AI crawlers, which are
# named explicitly below so nobody has to guess. The public pages are
# pre-rendered HTML (scripts/prerender.mjs), so crawlers that do not run
# JavaScript still get the full content.
#
# One group for everybody. A crawler obeys only the group that names it most
# specifically, so rules written under one name bind that crawler alone; here
# every name shares the one rule set below. The group has no blank lines on
# purpose: older parsers end a group at the first one.
#
# Named after "*": the search engines (Googlebot, Bingbot), then the AI answer
# engines and assistants (Google AI Overviews / Gemini, ChatGPT, Claude,
# Perplexity, Meta AI, Apple Intelligence, DuckDuckGo, Common Crawl).
#
# The Disallow lines keep the admin and account surfaces out of search
# results. That is a convenience, not a security control; the real protection
# is server-side.
